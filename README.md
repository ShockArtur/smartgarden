# 🌿 SmartGarden 2 — План и Уход

Веб-приложение (PWA) для планирования дачного участка: план в метрах со спутниковой подложкой, сезоны, грядки и посадки, автоматические задачи ухода, онлайн-база из 111 культур, мудборд идей и дневник роста.

**Открыть:** https://btrtmr18.github.io/smartgarden/

На телефоне: открыть ссылку в Chrome → ⋮ → «Установить приложение» (или «Добавить на главный экран»). Работает без интернета, все данные хранятся на устройстве; бэкап — ⚙️ → «В файл».

## Структура
- `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` — готовое приложение (то, что публикует GitHub Pages)
- `plants-db/` — **онлайн-база растений** (244 культуры: овощи, зелень, ягоды, плодовые, грибы, цветы, кустарники, деревья, сидераты):
  - `v2/index.json` — лёгкий список всех культур (~30 КБ), телефон скачивает его первым;
  - `v2/cat-*.json` — полные карточки по категориям, подгружаются при открытии категории;
  - `plants.json` — вся база одним файлом (для старых версий и Google Apps Script).
  - Править базу: `source/plants-db/plants.source.mjs`, `plants.more.mjs`, `plants.decor.mjs` → `npm run plants` → скопировать `source/public/plants-db/` в корень.
- `source/` — исходный код (React + Vite + Tailwind), ТЗ и документация

## Обновить приложение
1. Внести правки в `source/`, собрать: `cd source && npm install && npm run build`
2. Скопировать `source/dist/index.html` и `source/plants-db/plants.json` в корень репозитория → закоммитить.

## История версий
- **v2.3.3** — исправлена кнопка «Сбросить и создать участок заново» (и другие подтверждения: удаление объекта, записи дневника, подложки, загрузка бэкапа) — теперь своё окно вместо системного, которое блокируют встроенные браузеры. Обновления сами приходят на телефон: страница приложения берётся из сети, при выходе новой версии старый кэш удаляется.
- **v2.3.2** — новый компас: буква «С» неподвижна над компасом, поворачивается стрелка (красный конец показывает на север).
- **v2.3.1** — количество растений на грядке/клумбе можно вписать вручную (тап по числу → цифровая клавиатура).
- **v2.3 «Дизайн цветника»** — база 244 культуры (78 цветов, 21 декоративный кустарник: многолетники, луковичные, однолетники, злаки, почвопокровники, лианы, хвойные) с цветом, высотой и месяцами цветения; режим 🌸 «Цветение» на плане (по месяцам, клумбы раскрашиваются цветущими растениями); конструктор клумбы — палитры, полоса цветения с провалами и подбором растений на пустой месяц, ярусы по высоте, проверка «солнце/тень»; высокие растения на плане встают в центр/назад; «Миксбордер» и «Рабатка» в каталоге; новые зоны по умолчанию — клумба.
- **v2.2.1** — в настройках раздел «Карта на экране»: ползунок поворота карты (пока тянете — настройки прозрачные и видно карту), «Север вверху», «По стороне входа…»; отдельный ползунок «Где север» для компаса.
- **v2.2** — база расширена до 178 культур, новые категории «Грибы» (13, включая лесные с деревьями-партнёрами) и «Деревья»; онлайн-база разбита на индекс + категории (экономия трафика); «Мои» (♥ и посаженные на плане) сохраняются на телефон с описанием и фото из Википедии и работают без интернета; в каталоге — «Грибная грядка» и «Пни / чурбаки».
- **v2.1** — поворот плана по стороне участка (сторона входа внизу, сохраняется); поворот строений с шагом 5° относительно плана, транспортир с углом при повороте, кнопки ↺ ↻ по 5°; сетка выровнена по участку.
- **v2.0** — первая рабочая версия: мастер участка (адрес + спутник / рисование), редактор плана, сезоны, онлайн-база 111 растений, автозадачи, идеи, дневник, локальное хранение и бэкап.
