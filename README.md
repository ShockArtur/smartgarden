# 🌿 SmartGarden 2 — План и Уход

Веб-приложение (PWA) для планирования дачного участка: план в метрах со спутниковой подложкой, сезоны, грядки и посадки, автоматические задачи ухода, онлайн-база из 111 культур, мудборд идей и дневник роста.

**Открыть:** https://btrtmr18.github.io/smartgarden/

На телефоне: открыть ссылку в Chrome → ⋮ → «Установить приложение» (или «Добавить на главный экран»). Работает без интернета, все данные хранятся на устройстве; бэкап — ⚙️ → «В файл».

## Структура
- `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` — готовое приложение (то, что публикует GitHub Pages)
- `plants-db/plants.json` — онлайн-база растений (приложение скачивает её один раз и обновляет раз в неделю)
- `source/` — исходный код (React + Vite + Tailwind), ТЗ и документация

## Обновить приложение
1. Внести правки в `source/`, собрать: `cd source && npm install && npm run build`
2. Скопировать `source/dist/index.html` и `source/plants-db/plants.json` в корень репозитория → закоммитить.
